## 🎨 Design

- Minimal, type-first layout with **Instrument Sans**, **Geist Mono** and a hand-drawn accent font
- 🌗 Dark and light themes, remembered per visitor
- Soft scroll-reveal animations, a sticky blurred nav, fully responsive
- Custom hand-drawn anime-style avatar as the favicon
- No framework and no tracking: one HTML file, one CSS file, a little JS

## 🚀 Run it locally

```bash
git clone https://github.com/MuhammadFaizan-prog/Manahil_Amir_portfolio.git
cd Manahil_Amir_portfolio
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```
